# Add your images here

Use `portrait/` for your portrait, `projects/` for project screenshots, and `photography/` for your own photographs. The folders start empty on purpose.

Set the corresponding path in `src/content.js`, relative to `public/`, such as `images/photography/first-light.webp`. Do not include `public/` or a leading slash.

Use photos you own or have permission to publish. Avoid identifiable private information in screenshots. See `docs/EDITING.md` for recommended image sizes and examples.
